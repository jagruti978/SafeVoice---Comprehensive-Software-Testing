# SafeVoice - Comprehensive Software Testing

## Project Overview

SafeVoice is a Women Safety Issue Reporting Web Application designed to provide a secure platform for reporting, managing, and resolving safety-related issues.

This repository contains comprehensive software testing performed on the SafeVoice application using different testing methodologies and automation tools.

---

## Features Tested

- User Authentication
- Issue Reporting
- Resolver Assignment
- Solution Submission
- Issue Acknowledgement
- UI Validation
- Performance & Stress Testing

---

## Testing Types Performed

- Unit Testing
- Integration Testing
- System Testing
- UI Testing
- Performance Testing
- Acceptance Testing

---

## Technologies Used

### Application Stack
- HTML
- CSS
- JavaScript
- EJS
- Node.js
- Express.js
- PostgreSQL

### Testing Tools
- Selenium WebDriver
- TestNG
- Apache JMeter
- Postman

---

## Testing Environment

- Browser: Mozilla Firefox
- Deployment Platform: Render
- IDE: Eclipse IDE

---

## Performance Testing Summary

| Test Type | Users | Result |
|------------|-------|---------|
| Performance Test | 50 Users | Stable |
| Stress Test | 100 Users | Stable Under Load |

The application handled concurrent users successfully with no critical failures.
